# 功能说明

README 里每一项的细节和规则。数字和规则都来自实测（调试记录），验证过程见 [REFERENCES.md](../REFERENCES.md) 的「验证记录」。

## 本局页


1. **本局设定**：模式（决定可出现的盟约池）、策略、禁用盟约、敌方领袖与特训敌人、自选干员（「推荐自选」只在开局自选编队之前显示，开打或选好之后就收起；确认自选编队后，右侧「已选择自选编队」列出的干员会自动记成本局自选）。停在「确认本局信息」页点 **截屏录入本局** 自动填禁用、领袖和特训敌人。
2. **当前阵容**：开启「实时」后自动同步场上和整备区的干员（阶级角标 + Core ML 小人模型，在 M 系列芯片的神经网络引擎上运行，一次约 0.1 秒），只显示一行「场上 N · 整备区 M」；点开干员详情、拖去出售等挡住棋盘的画面，以及商店收起 / 展开时镜头还在移动的画面都不计入。阵容按名字计数，不看格子（镜头一动格子会错位）：同一个人连续两次认出才加入，连续三次没看到才移除。手动纠正过的名字以后自动沿用。
   - **替身干员**：没拥有的干员在商店和棋盘上用替身模型显示（Pith、Sharp、郁金香、Stormeye、Misery、Mechanist、Raidian、Touch、领主·Sharp、预备干员）。商店卡按卡面印的盟约和终端等级认出真身（3 本的 Pith 卡是卡涅利安，郁金香卡是忍冬），建议写成「买 卡涅利安（卡面 Pith）」；棋盘上的替身按阶级和买过的牌还原成真身。手动点 **识别场上** 会出一行紧凑的结果，拿不准的标「?」点开从候选里选，「采用」后写入阵容。
3. **能玩的路线**：路线卡片自动换行排列（窄窗口也能全部看到），手上已经有人的路线排在前面并标「已有 N」，分数最高的标「推荐」；自动跟随的路线只有在别的路线明显更好、或者你手上多出两个以上的人属于另一条路线时才换，不会因为阵容多认一个人就来回跳。按模式池、禁用、策略（暴躁铁皮 / 优等生 / 变形同构的棋子规则，以及各本家策略、众志合一、外勤医疗等）、敌情（飞行要远程或领主、高防偏法术、高法抗偏物理）和当前阵容，给出每个可用本家的成型阵容与 开局(2本) → 前期(3本) → 中期(4–5本) → 后期叠层(6本) → 成型 的完整路线；每个终端等级都有节奏（抢升本 / 补牌 / 稳升 / 满本）、该买谁、见到就留的牌、升本与资金建议、转职装备。当前阶段按终端等级高亮。
   - **小盟约路线**：除了每个本家的「本家Ⅱ（6人）」路线，还会给出最好的 3 条「两个小盟约Ⅱ（各 3 人）+ 本家Ⅰ（3 人）」路线（如 聚合Ⅱ+不屈Ⅱ · 乌萨斯Ⅰ），已经在做的小盟约优先；路线上的小盟约带图标列出。
   - **新的一局自动识别**：回合数从 3 以上连续两次读到 1，就自动清空上一局的阵容（保留模式和策略），调试记录也换新文件夹。「确认本局信息」页在开局前出现时会顺手读出禁用盟约、敌方领袖和特训敌人，清空时保留这些；对局中从 HUD 打开的同一页面不会覆盖已有的禁用。
   - **看队友在做什么**：休整期打开玩家列表（左边一排「前往观战」）时读出每位玩家行里的盟约，联防 / 观战别人棋盘时读顶栏；别人在做的本家（列表里有、或顶栏激活 / 有层数算 1 人，只是顶栏上有算半个）会让该路线分数每人打 15% 折，并写明「另有 N 名玩家在做阿戈尔，牌会被抢」。玩家列表挡住棋盘时不给站位、上场建议。
   - **路线不乱跳**：自动跟随的路线每回合最多自动换一次（除非另一条路线多用到你手上 3 个以上的人）。
   - 每个干员下面标出怎么拿：「现在能刷」「精锐奖励/升本」（高一阶）「N本才出」「1/3」「2/3 差1精锐」「自选」「赠送」。
   - **装备给谁**：主C 拿攻击 / 技力、前排拿防御 / 生存；攻击随盟约层数涨的干员（如蓝毒）排在最前。已买的装备会写出该给谁。装上就销毁的道具（简易通讯机、寻呼模块、人事部记录、随身身份牌、博士投影、拟态物质、信标、经济道具）会写怎么用：简易通讯机这类「拥有该干员第一盟约」的装给第一盟约是本家的干员（没有就装给小盟约的），买下的那一回合推荐操作里会出现「装备 X」。
4. **自动识别**：战场按地砖颜色自动认出（不用手选），回合 / 资金 / 卡价 / 升本价 / 顶栏盟约层数用游戏字体模板读取，终端等级（I–VI）用从 Mac 客户端采的图形模板读取；资金只读金币图标右边的数字。作战中自动暂停，资金和等级也只在自己的休整期更新。联防时按棋盘下方的标签区分：「自己」是自己的棋盘，「名字#1234」是队友的；联防开始 / 结束那几帧没有标签时，用顶栏盟约和自己的比对。
5. **推荐操作 + 游戏内高亮**：开启「实时」后，按当前终端等级那一阶段的路线建议，结合商店里的牌和价格、资金、升本价、冻结状态，直接在游戏画面上框出：该买的牌（按顺序编号）、升本、刷新、冻结 / 解冻；休整期还会标出该上场 / 下场 / 出售的干员，战场认出后给出每人站的格子和朝向。每类都能在「显示…」里单独关。
   - **站位**：敌人从红门沿地图路线走向蓝门。先定挡人点：近战够每路一个、且路上有红地板 / 蓝箭头（敌人踩过会变强），或两路到蓝门前一格才汇合时，每路各挡一个；否则在两路汇合处挡，后面留第二道防线。挡人的朝向敌人来的方向；远程站在打得到挡人点前一两格的位置，不站敌人会走到的格子；奶位站在射程够得到挡人的位置。
   - **本回合敌人路线**：按模式和回合查出这回合打哪一关，用那一关的路线站位（只有一路地面敌人时就守这一路；关卡模板里人少的路不单独派人挡）；飞行敌人不吃阻挡、近战打不到（领主除外，如烈夏、银灰），远程和领主会顺带罩住飞行航线。路线画在游戏画面上（地面红线、飞行青色虚线、领袖紫色，起点写是哪种），「显示…」里可关。关卡里列的是这回合**所有可能的怪组**的路线（每局随机出其中一组）。**人数不显示**：关卡文件里的人数只是模板，每局换进去的怪组人数不一样（光第 2 回合就从 2 个到 10 个不等）（例：m02 第 2 回合关卡写 6 个，实际来了 10 个萨卡兹刀兵），准确人数要看游戏里的敌人预览；在游戏里点开敌人列表后，会按名单筛掉不来的（例如名单里没有飞行敌人就不画飞行路线）。只在棋盘和上次对好的镜头一致时才画：点开敌人列表时镜头会移到敌人站的区域，这时不画。
   - **战场小地图**：推荐操作下面写「第 N 回合敌人：地面 X 路 · 飞行 Y 路」和下回合有哪些，并画一张小棋盘（地形、特殊格、敌人路线、场上干员、建议站的格子和朝向；认不准的干员带「?」）。这回合有飞行敌人而场上能打飞行的（远程和领主）不到 2 名时会提醒。
   - **敌人列表**：休整期点开游戏里的敌人面板（「悬赏」「敌人」），会读出这回合的敌人名字，标上飞行 / 法伤 / 高防 / 高法抗，面板往下滚动时会补全；AI 教练也会拿到这份名单。
   - **特殊格**：红地板（活性源石）上的干员攻击 / 攻速提升但持续掉血，适合远程，不给挡人的；蓝箭头（优化模块）攻速提升；沼泽降攻速，谁都不站；隐匿格里的敌人打不到。战场认出后，本局设定里会写出这张图有哪些特殊格。
   - 阵容建议一次只给能马上做的：有空位才「上场」（最多 2 个），没空位时给一组「下场 / 卖 A → 上场 B」；整备区快满（6 个以上）才建议卖 1 个；同名的第二张等合成，不重复建议上场；站位一次最多 3 步（先挡人的）。
   - 冻结商店前、或抢升本阶段升完本之后，剩下的钱先买有用的牌（不买要留到下回合的那张），再冻结。
   - **资金规则**（从 7 局调试记录核实）：剩的钱**留不到下回合**（利滚利除外）；每回合发的钱按回合固定（4、5、6 … 11），加上悬赏等额外收入；升本价在同一本里**每回合降 1**（如 2→3：8、7、6、5…）。所以升不起时不让你「攒钱」，而是写「下回合升本价 X、资金约 Y，下回合就能升」或「约 N 回合后升得起」，这回合的钱拿去买有用的牌或刷新。利滚利、得闲饮茶、业务指标等改资金规则的策略单独处理。
   - **下回合资金**：顶部显示「下回合约 X 资金 · 升本价 Y」，按本回合开局资金比基础收入多出来的部分（悬赏、经济装备）估；在 7 局 42 次换回合里 29 次算准、35 次误差在 1 以内，差得多的是悬赏开始和结束那一回合。
   - 升本只在终端等级、资金、升本价都读到且钱够时才框。
   - 三合一（合成精锐）后得到「晋升调配特许」，商店刷出几名比当前终端高一阶的干员（价格是青色的 0，只能免费选 1 名），会框出最值得拿的那一张，并写明理由（路线需要 / 能接上已有盟约）。
6. **选择弹窗**：悬赏决策（两排六张；按卡上写的敌人和奖励认卡，按敌人有效血量（血量 × 护甲，两条命翻倍）和**你现在的阵容强度**（按阶级加权：1 阶算 1，6 阶算 8）估「稳拿 / 能打 / 很难打」，算期望资金并扣掉漏怪掉血的风险（约 1.5 资金，Boss 3）；阵容弱时会选简单的；都不划算时推荐不给钱但零风险的源石虫；别人已经选走的卡（变浅灰、角上有头像）不推荐，你那一行打了 ✓ 就不再推荐）、道具补给 / 机密商店（按路线评装备）、战术决策（加成路线盟约优先），在画面上框出推荐的那张；开局自选编队只推荐和能玩的路线有关的（每排最多两张，同分的写「任选」，无关的不列；有飞行敌人时能打飞行的优先）。
7. **AI 教练**：一键「这回合怎么做」（⌘↩）。支持 DeepSeek、通义千问（百炼）、Claude，以及任意 OpenAI 兼容接口（含本地 Ollama）。流式显示并标出首字和总耗时。回答强度三档：快（精简局面、约 100 字、不让模型先思考，默认）、标准（附完整资料，约 300 字）、深入（完整资料并让模型先思考，DeepSeek 打开思考、Claude 用 high）。弹窗（悬赏、补给、机密商店、战术、自选编队）开着时问的是选哪张。模型只输出了思考、或什么都没回时会写明原因。

8. **特别关注**：本局设定里加想要的干员，商店一出现就高亮「关注 xx」并响一声（每回合一次），不管推荐买不买。
9. **战绩**：新的一局开始（或点「开始新的一局」）时自动记下上一局（打到第 3 回合以上才记）：模式、策略、地图、打到第几回合、等级、阵容、激活的盟约、跟的路线、领袖。名次自己在每条记录右边选，「战绩」页统计对局数、平均回合、平均名次、前四率，以及各盟约 / 策略的局数和平均名次。记录存在本机设置里（最多 300 局），不写文件。
10. **出局后自动暂停**：被淘汰后游戏会一直显示别人的棋盘（观战）。整个休整期都在别人的棋盘上（约 20 秒），或读到「已被淘汰」，就暂停计算：不再给建议、不再存调试帧、每 4 秒才看一次画面，同时把这局记进战绩（打到的回合按最后一次在自己棋盘上的算）。新的一局开始或回到自己的棋盘时自动继续。
11. **快捷键 ⌃⌥H**：隐藏 / 显示小助手窗口和游戏内高亮（截图、直播时用），隐藏时点程序坞图标也能叫回来；设置里可关。

另有图鉴（干员 / 装备 / 盟约 / 策略 / 敌人）和设置（窗口、识别间隔、画面裁切、AI 服务）。

## 已知限制

- **磁盘快满时文字识别会出错**（「文字识别出错 / CRImageReaderError / e5rtError 13」）：磁盘剩余很少时 macOS 会清掉神经网络引擎编译好的模型缓存，已经在用 Vision 文字识别的进程之后每次识别都失败，直到进程退出。小助手把文字识别放在单独的 `OCRWorker` 进程里，出错就自动重启它（重启后第一次识别要等 5–20 秒）；磁盘剩余少于 30 GB 时状态栏会提示。根治办法是清理出 30 GB 以上的空间。调试模式在剩余不到 15 GB 时自动停存截图。

- 悬赏决策已用 Mac 客户端截图验证（两局、各 6 张）；道具补给 / 机密商店 / 战术决策和自选编队页只按上游的 PC 布局实现，还没有 Mac 客户端截图验证。

- 场上认人只用了角标 + 小人模型 + 本局候选过滤，没有移植 StrongholdAssistant 的模板融合和跨帧身份追踪；角标偶尔漏掉一个人（真实对局里棋盘最下一行偶发），靠「连续三次没看到才移除」兜住。召唤物、被特效遮挡的小人可能认错。
- 叠层为普通特性的理论估算，不考虑站位和装备；敌情规则只做了对空、高防、高法抗三条。
- 站位是简化规则（见上），不是 StrongholdAssistant / 鸿雪的模拟退火站位器，也没有战斗模拟（不算伤害、漏怪数）；按本回合真实路线挡人、罩飞行航线，但不知道具体出哪种怪、来多少个（敌人列表要你在游戏里点开面板才读得到）。m07、m08 两张图没有地图数据。
- 干员卡价按阶级核对（1 阶 2、2–4 阶 3、5 阶 4，来自几局调试记录的全部商店读数），读数和阶级对不上就按阶级算（灰色「买不起」的价签偶尔把 3 读成 1）；同一商店多数干员都对不上时当作真打折，保留读数。读不到时也按这个表估算，界面会注明。
- 回合数字在低分辨率截图上可能读不出（只影响显示）；资金、终端等级、剩余可放置数已在样例截图上验证。

- 准备页盟约禁用的颜色阈值照搬自 Windows 版，**还没有在 Mac 客户端的真实截图上验证**；无法判断的盟约会列出来，可以手动点选。
- 商店识别按 16:9 的 1280×720 参考坐标定位名称栏。如果窗口有标题栏或侧边工具栏导致定位不准，在设置中调整裁切。
- 数据为规程 V3_1 赛季。更新数据时，把 StrongholdAssistant 的 `data/*.json` 复制到 `Resources/data/` 后重新构建。
